FOLDER CONTENTS:
----------------
  JARVIS_FULL.py      ← Main app (single file, all-in-one)
  requirements.txt    ← Python packages list
  SETUP_AND_RUN.bat   ← First time setup + run directly
  BUILD_EXE.bat       ← Build JARVIS.exe (real Windows app)
  README.txt          ← This file

=====================================================
HOW TO RUN (2 ways):
=====================================================

WAY 1 — Run directly with Python (easiest):
  1. Double-click SETUP_AND_RUN.bat
  2. Done! JARVIS window opens.

WAY 2 — Build real .exe app:
  1. Right-click BUILD_EXE.bat → Run as Administrator
  2. Wait 2-4 minutes
  3. JARVIS.exe appears on your Desktop
  4. Double-click JARVIS.exe anytime!

=====================================================
REQUIREMENTS:
=====================================================
  - Python 3.8 or higher (3.14 works too)
  - Ollama running: open terminal → "ollama serve"
  - Models pulled:
      ollama pull qwen2.5:7b
      ollama pull llava:latest
  - Microphone connected
